## STRIDE 6범주 (상세 위협모델은 04-architecture — 여기선 축 마킹)

| 범주 | 상태 | 처리 |
|---|---|---|
| Spoofing | Partial | **Assumed**: Supabase Auth 매직링크 1계정, 공유 링크는 추측 불가 토큰. Q3 답(개인+공유)으로 범위 확정 → 04에서 상세 |
| Tampering | Partial | **Assumed**: HTTPS 전용 + Supabase RLS(소유자만 쓰기) → 04에서 상세 |
| Repudiation | Clear(해당없음) | 단일 사용자 개인 도구 — 부인 방지 요구 없음. Accept 사유 04에 기록 |
| Information Disclosure | Partial | **Assumed**: 기본 비공개, 공유는 opt-in 링크 토큰만. 여행 일정 = 위치·일정 민감정보임을 04에서 명시 |
| Denial of Service | Partial | **Assumed**: 외부 API 쿼터 고갈이 주 리스크(악의적 DoS보다) — 검색 디바운스·캐싱·쿼터 경보 → 04·07 |
| Elevation of Privilege | Partial | **Assumed**: RLS 정책 = 소유자 외 쓰기 불가, 공유 토큰은 읽기 전용 뷰만 → 04·05 |
