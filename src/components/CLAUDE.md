프로젝트 표준·네비게이션은 `AGENTS.md`, 다음-할일은 `NEXT.md`를 따른다.

## 목표

캔버스(지도+리스트)·타임라인·인증·여행 목록 UI. 데이터 접근은 `src/lib/`를 경유한다.

`canvas/` `auth/` `common/` `trips/`
읽기 전용 입력: `docs/design/03-prd.md`(요구·화면) · `SPEC.md`

## 핵심 관례

- **지도 SDK를 컴포넌트에서 직접 import 하지 마라.** `src/lib/map`의 `MapProvider`만 소비 (#2)
- 지도 인증은 mount **이후 비동기로** 실패할 수 있다 — SDK가 네임스페이스를 비운다.
  `navermap_authFailure` 훅 구독 + SDK 호출 방어 + 안내 배너를 유지하라(회귀 테스트 3건 존재)
- **Day 내 순서는 통합 `position`.** 시각으로 정렬하지 마라 (#15).
  Day 지출 합계 = Stop + Leg (#24)
- 사용자 대면 문구는 해요체·능동형·긍정형. CTA는 다음 행동을 서술("보관함에 담기").
  **에러 화면엔 항상 다음 행동 버튼**
- 저장 결정은 3지점 유지 — 카테고리 버튼("식당으로 담기")이 곧 저장 (T6-2)
- iOS 설치형 PWA는 Safari와 세션이 격리된다 — 인증 기본은 **OTP 코드 입력**, 매직링크는 보조 (#13)
- 핀 겹침(클러스터링)은 미해결 — 별도 라이브러리 필요로 보류(T6-3)
